# Third-party provenance

This repository does not distribute the HAFusion datasets. On first run, the entrypoints download `data_NY`, `data_Chi`, and `data_SF` from the pinned upstream revision into the local working directory. The HAFusion reference model and downstream evaluation contract were reorganized from the same source revision.

- Project: HAFusion
- Paper: *Urban Region Representation Learning with Attentive Fusion* (ICDE 2024)
- Upstream: <https://github.com/MiRuacle24/HAFusion>
- Dataset download: <https://github.com/MiRuacle24/HAFusion/archive/73fbe911901ada71bb40129e19d86dedb9b9602c.zip>
- Paper: <https://arxiv.org/abs/2312.04606>
- Frozen upstream commit: `73fbe911901ada71bb40129e19d86dedb9b9602c`

No explicit license file was present in the audited upstream revision. Availability on GitHub does not grant redistribution rights; check the upstream terms before reusing its data or code.
